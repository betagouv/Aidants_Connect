Les applications d’authentification génèrent des codes à usage unique pour s’authentifier en toute sécurité sur un service.

  • Si vous disposez déjà d’une application d’authentification sur votre téléphone, pour un autre service, vous pouvez l’utiliser pour Aidants Connect.
  • Si vous ne disposez pas déjà d’une application d’authentification, téléchargez sur votre téléphone l’application de votre choix. Quelques exemples :
    • FreeOTP Authenticator
    • Google Authenticator
    • Microsoft Authenticator

Une fois l’application installée sur votre téléphone, passez à l’étape suivante.
